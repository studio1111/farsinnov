# Farsinnov Studio

وب‌سایت استودیوی Farsinnov برای طراحی و توسعه محصولات دیجیتال، شامل وب‌سایت، فروشگاه، وب‌اپلیکیشن و اپلیکیشن موبایل.

## تجربه و معماری

این پروژه یک تجربه فارسی RTL، سینمایی و تعاملی است که با React و Vite ساخته شده و بدون وابستگی به سرویس Backend اجرا می‌شود.

- Hero سینمایی با ماشین دیجیتال، عمق، نور و تعامل pointer/scroll
- مسیر خدمات ۶ مرحله‌ای از ایده تا رشد
- Portfolio تعاملی با ترکیب 3D، Cyberpunk و Case Study
- بخش اصول طراحی و توسعه
- فرآیند ۴ مرحله‌ای پروژه
- معرفی تکنولوژی و مسیر مقیاس‌پذیری
- FAQ تعاملی
- فرم درخواست پروژه با اعتبارسنجی سمت کاربر
- Dark / Light
- Responsive برای موبایل، تبلت و دسکتاپ
- Reduced Motion و حالت fallback برای مرورگرهای قدیمی‌تر
- دسترسی‌پذیری پایه شامل focus states، skip link و وضعیت فرم
- آماده اتصال به Supabase در مرحله Backend

## اجرا

```bash
npm install
npm run dev
```

برای تست:

```bash
npm test
```

برای Build:

```bash
npm run build
```

## وضعیت Backend

در این نسخه فرم درخواست پروژه عمداً محلی است و اطلاعات را به سرویس خارجی ارسال نمی‌کند. اتصال Supabase باید در مرحله بعد و با تعریف دقیق مدل داده، امنیت RLS و پنل مدیریت انجام شود.

## الهام

جهت هنری پروژه از الگوهای مفهومی ویدیوهای **Rodrigo Olivares - Crea con IA** الهام گرفته است، اما پیاده‌سازی مستقل است و از کد یا دارایی اختصاصی آن‌ها کپی نشده است.
