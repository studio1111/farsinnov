# Farsinnov Studio

وب‌سایت استودیوی طراحی و توسعه Farsinnov برای فروش وب‌سایت، فروشگاه، وب‌اپلیکیشن و اپلیکیشن.

## جهت طراحی

این نسخه از الگوهای تکرارشونده در ویدیوهای کانال **Rodrigo Olivares - Crea con IA** الهام مفهومی گرفته است: ساخت سریع، طراحی سینمایی، حرکت معنادار، محصول‌محوری و معماری قابل توسعه. پیاده‌سازی مستقل است و از کپی مستقیم دارایی یا کد ویدیوها استفاده نمی‌کند.

## قابلیت‌های فعلی

- Hero سینمایی با عمق و عناصر سه‌بعدی CSS
- کارت‌های تعاملی خدمات
- Dark / Light
- Responsive
- Reduced Motion
- فرم تماس سمت کاربر
- ساختار آماده برای اتصال Supabase
- RTL و فارسی

## اجرای محلی

```bash
npm install
npm run dev
```

## مرحله بعد

اتصال Supabase برای ذخیره درخواست‌های پروژه، پنل مدیریت و داده‌های قابل ویرایش.
