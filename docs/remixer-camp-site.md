# Remixer-inspired Camper Website

A standalone Persian RTL business website inspired by the latest website-building workflow reviewed from Rodrigo Olivares' video.

## Route

- Local: `/camp`
- Production on GitHub Pages: `/farsinnov/camp`

## Included

- Cinematic hero section
- Featured camper fleet
- Full camper catalog toggle
- Dark / light mode
- Responsive mobile navigation
- Story / methodology section
- Booking request form
- Client-side booking validation
- Reduced-motion accessibility support
- Reusable camper data module
- Node behavior tests

## Test

```bash
npm test
```

The project is intentionally implemented as an independent original design. It reproduces the product concepts demonstrated in the reference workflow, not the original site's branding, copy, or proprietary assets.
